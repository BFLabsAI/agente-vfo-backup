## Regras de Implementação

1. **Cada automação dispara um áudio** — o agente NÃO deve enviar texto antes da automação.
2. **Após cada áudio, o agente deve enviar UMA pergunta com CTA** via `send_text_message()` — nunca mais de uma pergunta.
3. **O CTA deve ser adaptado à etapa do funil:**
   - Antes da automação 1 → CTA para enviar conteúdo explicativo
   - Após automação 1 → CTA para fechar/avançar
4. **Após o CTA, AGUARDE a resposta do lead** — não dispare outra automação na mesma rodada.
5. **Cada automação deve ser usada no máximo 1 vez por lead** — se a mesma objeção surgir novamente, responda por texto.
6. **O agente deve identificar a situação pela mensagem do lead** — usar keywords como "computador", "tempo", "medo", "mãe", "faculdade", "cristã", "seguro", "profissão", "fora do Brasil".

|------|------|---------|-----------|
| `precisa_computador_sent` | bool | False | Automação "precisa de computador" enviada |
| `tempo_resultados_sent` | bool | False | Automação "tempo de resultados" enviada |

| `experiencias_ruins_sent` | bool | False | Automação "experiências ruins" enviada |

| `outro_pais_sent` | bool | False | Automação "outro país" enviada |

| `faz_faculdade_sent` | bool | False | Automação "faz faculdade" enviada |
| `e_crista_sent` | bool | False | Automação "é cristã" enviada |

### Uso no código:
- **Antes de disparar:** verificar se `*_sent == False`. Se True, responder por texto em vez de re-disparar.
- **Após disparar:** setar `*_sent = True`.
- **get_lead_info():** incluir todas as flags na seção "objections" do retorno.
